# Widen camera Roll range to ±90°

**Date Added**: 2026-09-28
**Priority**: Low
**Status**: In Progress

## Problem Statement

Camera Roll is limited to -45°…45°, which is too narrow for some mounting setups (e.g. a camera mounted on its side).

## Functional Requirements

- Roll can be set from -90° to 90°, still in 1° steps.

## User Experience Requirements

- Slider and number input both honour the new range; typed values outside it are clamped.

## Technical Requirements

- Update `min`/`max` on the `#roll` range input and add them to `#roll-num` so the browser's spinner arrows respect them.
- Share-link parsing (REQ-008) clamps to the slider's `min`/`max`, so `rot=…,…,90` links work with no extra code.

## Acceptance Criteria

- [ ] Roll slider reaches -90 and 90.
- [ ] Typing 120 clamps to 90; typing -120 clamps to -90.
- [ ] A share link with roll 90 loads as 90.

## Dependencies

Affects REQ-008 clamping (automatically).
